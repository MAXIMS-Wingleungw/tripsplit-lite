TripSplit Lite 1.2
==================

完整離線靜態網站版本，不使用 <dialog>、ASP.NET Core、SQL Server、外部 CDN 或 Internet API。
專為本機及內部 IIS 伺服器託管設計。

主要修正與新增功能（v1.2.0）
--------------------------
1. 【修正一】手機底部導覽新增「更多」頁面：
   - 包含：成員管理、統計分析、每日匯率、行程切換及資料備份的專屬入口卡片。
   - 手機導覽欄加入當前分頁高亮狀態（Active Indicator）。

2. 【修正二】Modal 內即時錯誤提示：
   - 驗證錯誤直接在 Modal 頂部以醒目紅框提示，並自動平滑滾動，不再跳出或退出表單。
   - 使用者修訂輸入後即可再次送出，避免輸入內容遺失。

3. 【修正三】付款人金額自動填入與智能平衡：
   - 新增帳目時預設勾選首位成員並自動填入最終金額。
   - 若只有一名付款人，輸入基礎金額或調整稅費時，金額即時自動聯動填入。
   - 提供「均分付款」與「填入剩餘」一鍵輔助按鈕。
   - 即時顯示付款平衡狀態列（差額、平衡狀態）。

4. 【額外修正 A】結算沖銷（記錄還款）：
   - 建議轉帳旁新增「記錄已還款」按鈕，一鍵標記債務清償，即時沖銷餘額。
   - 支援檢視已記錄的還款清單，並提供撤銷功能。

5. 【額外修正 B】分攤方式切換優化：
   - 切換至「百分比」時自動將 100% 依人數均分，避免預設 1% 導致驗證失敗。
   - 切換至「精確金額」時提供自動均分功能。
   - 均分模式即時顯示每人應攤金額，並鎖定輸入框避免誤導。

6. 【額外修正 C】停用成員收支平衡修復：
   - 若成員停用前有未結清餘額，結算時自動納入該成員並標記 (已停用)，保證會計借貸永遠平衡為零。

7. 【額外修正 D】徹底消除 CSP 警告：
   - 全面改採 data-action 與 DOM 事件委派，完全移除 HTML 內的 inline onclick/onchange，完美符合嚴格 CSP。

8. 【額外修正 E & F】細節體驗改善：
   - 點擊頂部/側邊行程 Badge 可快速切換行程。
   - 防止在 Modal 拖曳選字釋放滑鼠時誤觸背景遮罩關閉。
   - iOS Safari 底部 Safe Area 邊距優化。

部署說明
--------------------------
1. 備份現有 IIS 目錄（如 C:\inetpub\wwwroot\TripSplit-Lite）。
2. 將此 TripSplit-Lite-Fixed 資料夾內的所有檔案直接覆蓋至伺服器的 C:\inetpub\wwwroot\TripSplit-Lite。
3. IIS Application Pool 可直接設為「No Managed Code」。
4. 於瀏覽器開啟 http://localhost/TripSplit-Lite/ （若為手機請關閉分頁重開或強制重新整理）。
