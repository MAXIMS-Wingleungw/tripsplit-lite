TripSplit Lite 2.0
==================

完整離線靜態網站版本，不使用外部 CDN 或 Internet API。
專為本機、內部 IIS 伺服器託管以及 GitHub Pages 設計。

版本升級與新功能（v2.0.0）
--------------------------
【階段一：交易輸入與分帳核心邏輯（底層核心）】
1. 精確金額分帳優化：
   - 支援人手輸入每位成員的精確分攤金額。
   - 自動計算：輸入前 N-1 位成員金額後，最後一位成員自動計算並即時帶出剩餘金額（基礎金額 - 已輸入總和）。
   - 防呆提示：若前面輸入總額超出基礎金額，最後一人金額計算 < 0，即刻標紅高亮顯示並顯示警告提示，禁止送出。

2. 附加調整支援金額與百分比：
   - 在「附加調整」旁新增「$ 金額」與「% 百分比」雙模式切換開關。
   - 百分比模式：系統根據基礎金額自動計算調整金額（例：基礎金額 HK$96 × 10% = HK$9.60）。
   - 計算出的最終金額即時連動更新至「付款人總額」與「分攤成員總額」。

【階段二：統計分析與成員細項頁（統計展示）】
3. 統計分析頁：所有實際使用過的貨幣分類與金額總計：
   - 自動彙整並分類列出本次行程中所有實際使用過的貨幣種類及各自的總消費金額與分類長條圖。

4. 統計分析頁：每日每位成員消費總額：
   - 以「日期 (Day 1 ~ Day N)」為維度，表格列出當天每位成員實際被分攤到的消費總額及當日全額，底部附帶累計總計行。

5. 新增「成員消費詳細頁」（獨立頁面）：
   - 從統計頁或成員頁點擊即可進入獨立的成員個人明細頁。
   - 支援頂部成員快速切換標籤（小明、小華、小強等）。
   - 顯示個人實際總分攤、代墊付款總計、目前淨額狀態與參與筆數。
   - 按日期展開顯示該成員參與的每一筆消費項目、總金額、個人實際分攤金額以及付款狀態。

【階段三：結算頁面優化（最終輸出）】
6. 結算頁面：新增「結算詳情」入口：
   - 每個貨幣餘額區塊新增「結算詳情與推導」按鈕。
   - 彈窗展示：
     (1) 收支淨額彙總表（總付款代墊 +、總分攤應付 -、沖銷還款 ±、最終淨額）。
     (2) 債務簡化推導過程（採用貪婪撮合演算法 Greedy Settlement，列出債權人、債務人及每一步沖銷金額與結餘）。
     (3) 涵蓋之原始消費明細清單。

【備份相容性保證（Backward Compatibility）】
- 完整相容舊版本（v1.0、v1.1、v1.2）匯出的所有 JSON 備份檔案。
- 匯入時若舊備份缺少 v2.0 專屬欄位（如 adjustmentMode、adjustmentValue），系統會自動平滑轉移並補齊預設值，無需任何手動修改。

部署說明
--------------------------
1. 建立新的 IIS 站台或複製此「TripSplit-Lite-V2」資料夾至伺服器目錄。
2. 亦可直接複製此資料夾的所有檔案覆蓋既有目錄。
3. 於瀏覽器開啟 http://localhost/TripSplit-Lite/ （若為手機請關閉分頁重開或強制重新整理）。
4. 在「設定與備份」中，可直接匯入先前的 JSON 備份檔案繼續使用。
