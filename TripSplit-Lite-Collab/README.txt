TripSplit Lite 2.1 Collab（即時協同共享版）
=========================================

全新升級：在 V2.0 基礎上加入 Google Firebase / Firestore 免費即時多人同步！
同行朋友只需用手機瀏覽器打開專屬連結或掃描 QR Code，即可即時共同記帳與分帳。
朋友免下載 App、免註冊登入，即開即用，網路正常時改動會自動即時同步！

【共享同步與重新開啟修正】
- 修正雲端模組未公開至 window.Cloud，導致自動初始化、編輯上傳及重開後即時訂閱被略過。
- 記住最後開啟或加入的行程；使用同一瀏覽器與網站網址重開時，自動恢復該行程及共享訂閱，不必重新輸入代碼。
- 首次雲端快照也會刷新畫面，並清除離線期間已在雲端刪除的舊資料；本機儲存期間不再忽略其他人的更新。
- 在行程清單分享另一個行程時，只會上傳該行程的資料，不會混入目前開啟的行程。
- 雲端寫入失敗會顯示錯誤，不再當作同步成功；診斷的讀取成功不代表寫入權限或即時訂閱也已成功。
- 部署時請一併更新 js/cloud.js 與 js/app.js，並在瀏覽器重新整理以載入新版程式。

【即時協同共享特色（v2.1.0-Collab）】
1. ☁️ 一鍵發佈雲端共享：
   - 任何本機行程皆可一鍵點擊「☁️ 共享行程」，系統自動將該行程與帳目上傳至 Firestore 雲端資料庫。
   - 自動生成專屬分享連結（URL 帶有 ?trip=TRIP_ID）與專屬行程代碼。
   - 內建手機 QR Code，朋友當面用手機相機一掃即可加入。

2. 🔗 零門檻加入共同編輯：
   - 方式一：朋友點擊分享連結，網頁自動識別並立即載入雲端資料並啟動即時同步。
   - 方式二：在「行程管理」點擊「🔗 輸入代碼加入行程」，貼上行程代碼或連結即可加入。

3. ⚡ Firestore 即時雙向同步：
   - 網路正常且雙方都已開啟同一共享行程時，新增、修改或刪除帳目、成員、匯率或還款會自動同步；實際延遲取決於網路及 Firestore 回應。
   - 貼心防干擾機制：若使用者正開啟彈窗輸入帳目，遠端更新會在背後刷新快取，不強制關閉使用者正在輸入的表單。

4. 🛡️ 本地快取與離線優先（Offline-First）：
   - 仍保留 IndexedDB 本機儲存，即使在無網路環境（如飛機上或訊號不佳處），本機資料依然完整無缺。
   - 頂部狀態標籤清楚標記「離線模式」、「本機儲存」或「即時共享中 ☁️」。

5. 🔄 備份檔案 100% 雙向相容：
   - 先前 V1.x、V2.0 匯出的 JSON 備份檔案可 100% 直接在此版本「設定與備份」中匯入還原！

【V2.0 完整核心功能全數保留】
- 精確金額分帳（支援手動輸入前 N-1 人，最後一人自動計算剩餘金額與防呆高亮警告）。
- 附加調整（支援「$ 金額」與「% 百分比」雙模式自動連動）。
- 統計分析頁（所有實際使用幣別分類長條圖與金額彙總、每日每位成員消費總額表）。
- 成員消費詳細頁（成員快速切換、每日消費與代墊明細、每日總額小計）。
- 結算詳情與推導（收支淨額總表、貪婪撮合演算法步驟推導、原始消費清單）。
- 嚴格 IIS CSP 安全設定，不含內聯事件，符合公司網路安全規範。

部署說明
--------------------------
1. 將「TripSplit-Lite-Collab」整個資料夾複製到伺服器目錄或上傳至 GitHub。
2. 在 IIS 中建立站台或應用程式指向此資料夾。
3. 透過電腦或手機瀏覽器開啟即可！

測試說明
--------------------------
1. 原有核心測試：以瀏覽器開啟 tests/test-runner.html。
2. 共享回歸測試（需 Node.js 18 或以上）：在此資料夾執行 node --test .\tests\cloud.test.cjs。
   涵蓋原有計算測試、獨立用戶間的新增/修改/刪除、重開恢復、首次快照、
   表單防干擾、跨行程隔離、共享連結自動加入及雲端失敗處理。
3. 自動化共享測試使用模擬 Firestore，不會讀寫正式 Firebase。
   正式部署後仍須以兩個裝置開啟同一行程，確認實際網路、Firebase 規則與同步行為。
